# Console Speedtest

Консольный скрипт на Python для замера скорости скачивания файла по указанному URL.

## Описание работы
1. Скрипт принимает URL целевого ресурса (например, тяжёлого изображения) через аргумент командной строки.
2. Последовательно выполняет **10 HTTP GET-запросов** в рамках одной сессии (`requests.Session`), дожидаясь полного ответа на каждый запрос.
3. Вычисляет общее количество скачанных данных, среднее время одного запроса и итоговую скорость скачивания.

## Единицы измерения
* **Объём скачанных данных:** Мегабайты (`МБ`, \(1\text{ МБ} = 1024 \times 1024\text{ байт}\)) и байты.
* **Среднее время запроса:** Секунды (`сек`).
* **Скорость скачивания:** Мегабиты в секунду (`Мбит/с`, \(1\text{ Мбит} = 10^6\text{ бит}\)).
